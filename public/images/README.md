# Adding your photographs

Drop your image files into the matching folder below, using the exact
filenames listed (or update the paths in src/data/*.ts to match your files).

- images/hero/hero-main.jpg           — full-screen hero background
- images/about/portrait.jpg           — About page portrait of Srinivasa
- images/about/behind-the-scenes.jpg  — Home intro section image
- images/cta/cta-banner.jpg           — full-width CTA section background
- images/academy/training-session.jpg — Academy page hero image
- images/portfolio/wedding-01.jpg ... wedding-04.jpg
- images/portfolio/newborn-01.jpg ... newborn-03.jpg
- images/portfolio/maternity-01.jpg ... maternity-03.jpg
- images/portfolio/model-01.jpg ... model-03.jpg
- images/portfolio/portrait-01.jpg ... portrait-03.jpg
- images/og-cover.jpg                 — social share preview image (1200x630 recommended)

Until a file exists at a given path, that spot on the site shows an elegant
placeholder with a label — never a stock photo — so it's always obvious what
still needs a real photograph.

To add more portfolio images beyond these, edit src/data/portfolio.ts.
